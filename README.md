# 미션 - 페어매칭관리 애플리케이션

## 기능 구현 목록
> 기능 작동 순서대로 작성

0. 파일 입력 및 크루 정보 저장
1. 기능 선택 및 검증
   - 예외 사항
     - 1,2,3,Q가 아닌 경우
       - 잘못된 형식입니다.
2. 페어 매칭
   1. 과정, 레벨, 미션 선택 및 검증
      - 예외 사항
        - 잘못된 형식인 경우
          - 잘못된 형식입니다.
        - 잘못된 과정인 경우
          - 잘못된 과정입니다.
        - 잘못된 레벨인 경우
          - 잘못된 레벨입니다.
        - 잘못된 미션인 경우
          - 잘못된 미션입니다.
   2. 해당 과정, 레벨, 미션에 매칭 이력이 있는지 확인
   3. 있다면 재매칭 여부 선택 및 검증
      - 예외 사항
        - 네, 아니오가 아닌 경우
          - 잘못된 형식입니다.
      1. 네인 경우
         1. 매칭 실행
         2. 매칭 페어가 이전에 같은 레벨에서 존재했는지 확인
         3. 존재했다면 재매칭
         4. 1~3번을 3번 반복했는데 성공하지 못하면 매칭 실패
            1. 과정, 레벨, 미션 선택으로 이동
         5. 매칭에 성공하면 페어 매칭 결과 출력
            - 페어 매칭 결과입니다.
            - 크루 이름(나온 순서대로 출력)
      2. 아니오인 경우
         1. 과정, 레벨, 미션 선택으로 이동
   4. 없다면 매칭 실행
      1. 매칭 실행
         2. 매칭 페어가 이전에 같은 레벨에서 존재했는지 확인
         3. 존재했다면 재매칭
         4. 1~3번을 3번 반복했는데 성공하지 못하면 매칭 실패
            1. 과정, 레벨, 미션 선택으로 이동
         5. 매칭에 성공하면 페어 매칭 결과 출력
            - 페어 매칭 결과입니다.
            - 크루 이름(나온 순서대로 출력)
3. 페어 조회
   1. 과정, 레벨, 미션 선택 및 검증
      - 예외 사항
        - 잘못된 형식인 경우
          - 잘못된 형식입니다.
        - 잘못된 과정인 경우
          - 잘못된 과정입니다.
        - 잘못된 레벨인 경우
          - 잘못된 레벨입니다.
        - 잘못된 미션인 경우
          - 잘못된 미션입니다.
   2. 해당 과정, 레벨, 미션에 매칭 이력이 있는지 확인
   3. 있다면 페어 매칭 결과 출력
      - 페어 매칭 결과입니다.
      - 크루 이름(나온 순서대로 출력)
   4. 없다면 예외 메시지 출력 후 과정, 레벨, 미션 선택으로 이동
4. 페어 초기화
   1. 페어 초기화 후 메시지 출력
      - 초기화 되었습니다.
5. 종료
   1. 프로그램 종료
