# 미션 - 페어매칭관리 애플리케이션

## 기능 구현 목록
1. 기능 선택
   - 예외 사항
     - 1,2,3,Q 가 아니면 예외 발생
       - “1”, “2”, “3”, “Q” 중 하나를 입력해야 합니다.
2. 페어 매칭
   1. 과정, 레벨, 미션 입력
      - 예외 사항
        - 형식이 올바르지 않은 경우
          - 올바르지 않은 형식의 입력입니다.
        - 과정이 “백엔드”, “프론트엔드”가 아닌 경우
          - 올바르지 않은 과정입니다.
        - 레벨이 “레벨1”~”레벨5”가 아닌 경우
          - 올바르지 않은 레벨입니다.
        - 레벨에 미션이 존재하지 않는 경우
          - 미션이 존재하지 않는 레벨입니다.
        - 존재하지 않는 미션인 경우
          - 올바르지 않은 미션입니다.
   2. 매칭 정보가 있는지 확인 후 없다면 3번 실행
      1. 매칭 정보가 이미 있다면 재매칭 여부 입력
         - 예외 사항
           - “네”, “아니오”가 아니면 에외 발생
             - “네”, “아니오” 중 하나를 입력해야 합니다.
      2. “네”라면 기존 결과 삭제 후 3번 실행 / “아니오”라면 "과정, 레벨, 미션 입력"으로 돌아가기
   3. 페어 매칭 실행
      1. 크루 리스트 랜덤으로 섞기
      2. 섞은 순서대로 2명씩 꺼내 페어로 만들기
         - 마지막에 3명이 남았다면 3명을 하나의 페어로 만들기
      3. 한명씩 이전에 페어 경험이 있었는지 확인해서 이미 페어 경험이 있다면 다시 1번으로 돌아가기
      4. 3회 시도까지 매칭이 안되거나 매칭을 할 수 있는 경우의 수가 없다면 에러 메시지 출력 후 기능 선택으로 돌아가기
      5. 매칭이 되었다면 매칭 결과를 출력한다.
3. 페어 조회
   1. 과정, 레벨, 미션 입력
      - 예외 사항
        - 형식이 올바르지 않은 경우
          - 올바르지 않은 형식의 입력입니다.
        - 과정이 “백엔드”, “프론트엔드”가 아닌 경우
          - 올바르지 않은 과정입니다.
        - 레벨이 “레벨1”~”레벨5”가 아닌 경우
          - 올바르지 않은 레벨입니다.
        - 레벨에 미션이 존재하지 않는 경우
          - 미션이 존재하지 않는 레벨입니다.
        - 존재하지 않는 미션인 경우
          - 올바르지 않은 미션입니다.
   2. 매칭 이력이 있다면 출력한다.
   3. 매칭 이력이 없다면 에러 메시지를 출력하고 기능 선택으로 돌아간다.
4. 페어 초기화
   1. 매칭 이력을 모두 삭제한 후 메시지를 출력한다.
      - 초기화 되었습니다.
5. 종료
    1. 프로그램을 종료한다.
