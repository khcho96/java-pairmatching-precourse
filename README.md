# 미션 - 페어매칭관리 애플리케이션

## 기능 구현 목록
> 기능 작동 순서대로 작성

1. 파일 입력 및 크루 정보 저장
2. 기능 선택 및 검증
   - 예외 사항
     - 1,2,3,Q가 아닌 경우 -> Menu
       - 잘못된 형식입니다.
3. 페어 매칭
   1. 과정, 레벨, 미션 입력 및 검증
      - 예외 사항
        - 잘못된 형식인 경우 -> Validator
          - 잘못된 형식입니다.
        - 없는 과정인 경우 -> Course
          - 없는 과정입니다.
        - 없는 레벨인 경우 -> Level
          - 없는 레벨입니다.
        - 없는 미션인 경우 -> Mission, Level
          - 없는 미션입니다.
   2. 기존 페어 매칭 결과 존재여부 확인
   3. 있으면 재매칭 여부 입력 및 검증
      - 예외 사항
        - 잘못된 형식인 경우 -> Menu
          - 잘못된 형식입니다.
      1. “네”이면 매칭 실행
         1. 매칭하는 하나의 페어마다 같은 미션에서 이미 만난 적 있는 페어인지 확인
         2. 이전에 만난적 있으면 다시 처음부터 매칭
         3. 매칭에 3번 실패하면 에러메시지 출력 후 과정,레벨,미션 선택 화면으로 이동
      2. “아니오”이면 과정,레벨,미션 선택 화면으로 이동
   4. 없으면 매칭 실행
      1. 매칭하는 하나의 페어마다 같은 미션에서 이미 만난 적 있는 페어인지 확인
      2. 이전에 만난적 있으면 다시 처음부터 매칭
      3. 매칭에 3번 실패하면 에러메시지 출력 후 과정,레벨,미션 선택 화면으로 이동
4. 페어 조회
   1. 과정, 레벨, 미션 입력 및 검증
      - 예외 사항
        - 잘못된 형식인 경우 -> Validator
          - 잘못된 형식입니다.
        - 없는 과정인 경우 -> Course
          - 없는 과정입니다.
        - 없는 레벨인 경우 -> Level
          - 없는 레벨입니다.
        - 없는 미션인 경우 -> Mission, Level
          - 없는 미션입니다.
   2. 기존 페어 매칭 결과 존재여부 확인
   3. 있으면 매칭 결과 출력
   4. 없으면 예외메시지 출력 후 다시 입력(과정, 레벨, 미션)
5. 페어 초기화
   - 초기화 후 메시지 출력
6. 종료
   - 프로그램 종료
